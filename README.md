**Investment Portfolio Tracker**

This project is an Excel-based portfolio tracking and performance analysis tool. Its purpose is to consolidate multiple investment holdings into one model, track portfolio value over time, and provide insights into diversification, allocation, and return contributions from individual securities. The tracker functions similarly to a simplified brokerage dashboard, while remaining fully transparent and user-controlled.

**Features**

The Excel model in this project includes:

- A transaction log for recording buy and sell activity
- A holdings dashboard that tracks price, market value, and allocation
- Realized and unrealized gain/loss calculations
- Automatic updates to total portfolio value based on current prices
- Asset and sector allocation visuals
- Daily and cumulative performance metrics

This tool combines multiple investment positions into one model, allowing users to see how portfolio changes impact returns, diversification, and risk exposure.

**How It Works**

1. Recorded transactions including ticker symbols, dates, share quantities, and purchase prices.
2. Calculated cost basis and holding value for each position.
3. Updated prices to determine current market value and unrealized gains or losses.
4. Generated allocation percentages across holdings, sectors, and asset classes.
5. Evaluated performance using realized and unrealized gains, dividends (if applicable), and portfolio totals.

The model is designed to simulate core features found in modern brokerage dashboards while offering transparency into every calculation.

**Why I Built This**

Most investors track individual stock prices but rarely understand how portfolio construction, allocation decisions, and realized vs. unrealized gains affect long-term wealth. Building this tracker provided hands-on experience with:

- Portfolio management concepts
- Risk and allocation awareness
- The relationship between position sizing and total return
- How investments contribute to performance over time

It also serves as a personal tool for monitoring real investments without relying solely on third-party platforms.

**Insights Gained**

Building and using this tracker provided a deeper understanding of:

- How portfolio allocation drives risk and return
- How market movements affect total wealth, not just single positions
- Why transaction history, cost basis, and position sizing matter
- The importance of tracking performance beyond price changes alone

These insights support more informed decision-making when managing personal investments.
